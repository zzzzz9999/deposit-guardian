## 项目简介

**租客卫士** 是一个面向租房者的维权助手，提供：

- 真实案例库（12 类 14 个场景）
- AI 智能对话引导（一步步帮你维权）
- 法律工具箱（证据清单、催款模板、维权时间轴）
- 租房相关法律条文速查（35 条精选 + 民法典全文 1260 条）

**技术栈**

| 层 | 技术 |
|---|---|
| 前端 | 纯 HTML + CSS + JavaScript（无框架） |
| 后端 | Python FastAPI + uvicorn |
| AI | Claude API（claude-sonnet-4-6，流式输出） |
| 数据 | JSON 文件（无数据库） |

## 快速启动

### 1. 安装依赖

```bash
cd deposit-guardian/backend
pip install fastapi uvicorn httpx python-docx python-dotenv pydantic
```

### 2. 配置认证

在项目根目录创建 `.env` 文件：

```
ANTHROPIC_AUTH_TOKEN=你的token
```

### 3. 启动服务

```bash
cd deposit-guardian/backend
python main.py
```

或使用 uvicorn 直接启动：

```bash
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### 4. 访问网站

打开浏览器访问 **http://localhost:8000**

> 刷新页面时按 `Ctrl+Shift+R` 清除浏览器缓存，确保看到最新版本。

案例库覆盖三大场景、12 个分类、14 个典型案例：

| 场景 | 分类 |
|---|---|
| 💰 押金纠纷 | 损耗纠纷 / 合同陷阱 / 中介跑路 / 拖延推诿 / 无中生有 / 长租爆雷 |

| 📋 签约陷阱 | 虚假房源 / 霸王条款 |

**使用方式**：
- 顶部搜索框：输入描述（如"房东说地板有划痕"）实时匹配案例
- 分组按钮：按押金纠纷 / 租住权益 / 签约陷阱快速筛选

### AI 维权对话

**地址**：`http://localhost:8000/chat.html`

核心功能，AI 扮演专业维权顾问，引导用户一步步维权。

**对话流程**：
1. 描述情况 → AI 追问关键信息（押金金额、租期、房东理由等）
2. AI 判断纠纷类型，援引对应法律条文
3. 给出「三步行动计划」（今天 / 3天内 / 不成功后）
4. 提供可直接复制的催款消息模板

**界面说明**：

| 区域 | 功能 |
|---|---|
| 左侧「历史」Tab | 查看所有历史对话，点击可恢复继续 |
| 左侧「案例」Tab | 根据对话内容自动推荐相关案例 |
| 左侧「法条」Tab | 常用法律条文速查，点击插入输入框 |
| 顶部阶段指示器 | 显示当前对话进度（了解情况 → 分析判断 → 给出方案） |
| 欢迎屏快捷按钮 | 6 种常见场景一键开始 |

**AI 搜索功能**：  
当用户提到特定平台（蛋壳、自如等）或询问最新进展时，AI 会自动搜索最新案例和法律信息并注入回答。

**法律原文链接**：  
AI 回复中出现「《民法典》第XXX条」时，旁边会自动出现「⚖原文」链接，点击跳转全国人大官方法律数据库。

### 法律工具箱

**地址**：`http://localhost:8000/tools.html`

包含三个 Tab：

#### 🔧 实用工具

| 工具 | 说明 |
|---|---|
| 证据清单生成器 | 按纠纷类型（损耗/合同/中介跑路等）生成定制化证据清单，可勾选进度 |
| 维权时间轴 | 输入退租日期，自动计算各维权节点截止时间（催款→投诉→诉讼） |
| 催款模板库 | 5 类模板（首次催款 / 升级催款 / 反驳损耗 / 格式条款无效 / 投诉信），一键复制 |
| 维权渠道速查 | 12345 / 住建委 / 法院 / 黑猫 / 12348 / 公安局 各渠道适用场景说明 |
| 常见误区 | 6 个常见错误认知纠正 |

#### 📚 法律条文库

35 条精选租房相关法律条文，覆盖 7 部法律：

- 《民法典》（租赁合同章 + 合同通则，共 27 条）
- 《消费者权益保护法》（4 条）
- 《宪法》（第 39 条，住宅不受侵犯）
- 《治安管理处罚法》（第 40 条，非法侵入住宅）
- 《城市房屋租赁管理办法》（2 条）
- 《民事诉讼法》（小额诉讼程序）

**搜索方式**：
- 搜索框输入关键词（押金、涨租、维修、买卖不破租赁、格式条款…）
- 标签过滤：核心条款 / 押金纠纷 / 租住权益 / 签约陷阱 / 维权程序
- 每条附有适用场景说明和官方原文链接

#### 📖 民法典全文

从官方 docx 解析的完整民法典，**1260 条全文**，支持：

- 关键词实时搜索（匹配条文内容和章节名）
- 按编筛选：第一编总则 / 第二编物权 / 第三编合同（含租赁合同 60 条）/ 第四编人格权 / 第五编婚姻家庭 / 第六编继承 / 第七编侵权责任
- 每页 30 条，带分页导航
- 搜索结果高亮显示匹配词

> **搜索提示**：民法典用词与日常用语不同，建议用：
> - `租赁` 代替「租房」→ 找到 60 条租赁相关条文
> - `定金` / `保证金` 代替「押金」
> - `出租人` / `承租人` 代替「房东」/「租客」
> - `违约` `损耗` `维修` 等法律术语

## API 接口

所有接口均以 `http://localhost:8000` 为基础地址。

### 案例相关

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/cases` | 获取所有案例，支持 `?category=xxx` 过滤 |
| GET | `/api/cases/{id}` | 获取单个案例详情 |
| GET | `/api/search?q=关键词` | 案例关键词搜索 |
| GET | `/api/categories` | 获取所有分类 |

### AI 对话

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/chat` | 流式对话（SSE），请求体：`{messages, enable_web_search}` |

**SSE 事件类型**：
- `searching`：AI 正在搜索最新信息
- `text`：流式文字输出
- `done`：回复完成
- `error`：发生错误

### 民法典

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/minfadian` | 搜索条文，支持 `?q=关键词&part=第三编&num=713&limit=30&offset=0` |
| GET | `/api/minfadian/parts` | 获取各编目录和条文数量 |

### 其他

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/news` | 获取精选租房资讯（6条内置数据） |

### AI 提示词（prompts.py）

AI 扮演「租客卫士」，遵循 5 步引导流程：
1. 了解情况（追问关键信息）
2. 判断类型（援引对应法律）
3. 给出三步行动计划
4. 提供即用消息模板
5. 搜索最新信息（需要时）

法律条文引用格式：`《民法典》第XXX条`（前端自动添加官方原文链接）

### 历史对话（localStorage）

对话历史存储在浏览器 `localStorage` 中，key 为 `dg_sessions`，最多保留 30 条。预置了 4 条示范历史对话（首次加载时注入，key `dg_seeded_v2`）。

## 常见问题

**Q：页面没有变化，还是旧版本？**  
A：按 `Ctrl+Shift+R` 强制刷新清除浏览器缓存。

**Q：AI 不回复 / 回复为空？**  
A：检查 `.env` 文件中 `ANTHROPIC_AUTH_TOKEN` 是否正确配置。

**Q：民法典搜索"押金"没有结果？**  
A：民法典用词是"定金"或"保证金"，搜"租赁"可找到所有租房相关条文（60条）。

**Q：如何更新民法典数据？**  
A：替换 `C:/Users/.../Downloads/` 下的 docx 文件后，重新运行：
```bash
cd deposit-guardian
python parse_minfadian.py
```
然后重启后端服务。

**Q：AI 历史对话显示"押金卫士"而不是"租客卫士"？**  
A：浏览器 localStorage 缓存了旧数据。打开浏览器开发者工具（F12）→ Application → Local Storage → 删除 `dg_seeded_v1` 和 `dg_sessions`，刷新页面即可。

**Q：端口 8000 被占用怎么办？**  
```bash
# Windows：查找并终止占用进程
netstat -ano | findstr :8000
taskkill /PID <进程ID> /F

# 或换端口启动
python -m uvicorn main:app --port 8001
```
